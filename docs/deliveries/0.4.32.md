# 0.4.32 — 模板批次失败集中处理

## 行为

- 代码审查、贡献报告的独立批次失败后记录并跳过，继续调度剩余批次，不自动重新触发失败项。历史第一期任务保持冻结模型、证据、窗口、预算及双评审合同，只修正失败隔离与恢复行为。
- 本轮独立批次结束后集中展示失败清单，支持选择 1–100 项一次重新触发。服务端在同一短事务内校验所有身份、版本和停止证明；任一项无效则整组选项回滚。重复请求不创建重复代次。
- 已验证结果和旧代次保持不变；未选或再次失败的项目继续保留，所有必需结果补齐后才进入依赖分析、复核和总结报告。需求代码评审使用相同的先执行、后选择策略，其就绪判断包含尚未创建会话的冻结原文章节。
- 旧版整体停止造成的未创建会话批次不显示为失败，任务恢复后自动接续其冻结输入。修正停止路径读取旧批次状态的缓存问题，并防止迟到的等待轮询停止用户刚发起的重试。
