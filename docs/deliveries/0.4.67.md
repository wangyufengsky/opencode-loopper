# 0.4.67 — 对话确认后制作 PPT

PPT 新建调整为持续对话：用户可以随时补充需求，助手在讨论阶段只读取项目资料，不执行设计写入或制作。助手回复完成、没有待回答的结构化问题且没有未发送草稿时，页面提供“确认需求并执行”。点击后，服务端冻结完整讨论记录并按该记录启动制作；确认请求带有幂等标识，重试不会重复创建制作任务。对话未完成或已有活动制作时，服务端拒绝确认。旧流程与历史授权继续按原协议恢复。

普通文本提问和回答不再被误判为缺失 `ppt_request_input` 后直接失败；讨论上下文从已保存轮次重建，并随后续对话提供给模型。制作授权持久化标记明确用户已确认，避免把模型自然语言回答当作确认。
