## 实施顺序

M1 模板来源、发起记录、迁移、动态入口；M2 共用文档需求；M3 静态评审；M4 开发编排；M5 联动回归与正式交付。

复用已有候选提交、生命周期、执行、验证和报告基础设施。模板来源独立于 executionMode；不得借用报告豁免跳过开发测试或双评审。文档和代码始终是待分析数据，不构成工具权限或外部操作授权。

验证需覆盖多文档冲突和遗漏、源引用、长文档、前后端链路、未实现与未知区分、分支冻结、原目录脏文件和租约、重启及未知投递、整体回归、历史升级。模拟 Provider 只证明协议与编排；真实模型效果单独记录。

不包含旧 DOC、OCR、评审执行测试、自动修复、多仓库、全仓库扫描、自动合并或远端发布。
