# 0.4.68 — 隐藏 PPT 对话中的通用完成提示

PPT 助手完成一轮对话时，服务端会将“本轮模型已完成；制作结果以作品检查和作业状态为准”保存为运行详情。讨论页此前既在对应消息下显示 `message.detail`，又在消息列表之后显示 `store.agent.detail`，因此同一条通用状态出现两次。现在两处都过滤该固定文案，并在全局状态与消息详情相同时只保留消息中的一处；制作检查失败等具体详情继续显示。
