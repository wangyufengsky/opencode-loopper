# 0.3.90：修复 Windows 发布工具测试夹具

## 原因与修改

推送 0.3.89 后，Windows CI 在 `project-tooling.test.mjs` 的缺失版本字段检查失败。夹具删除字段只匹配 LF，Windows checkout 的 CRLF 保留了版本字段，导致预期异常未发生。发布工具本身没有漏检缺失字段。

修正夹具的行尾匹配，增加缺失字段的直接断言，并分别运行 LF、CRLF 下的版本漂移、缺失字段、JAR 和标签占用检查。本机先运行新增 CRLF 场景复现失败，再修正通过；不放宽发布校验。

0.3.89 标签已推送，保持不可变；其 Release 工作流在发布前取消。修正版本顺延为 0.3.90，沿用 0.3.89 的文档执行、确认门禁与输出路径修复。
