# 0.4.64 — PPT 一键生成与对话修改

## 用户可见变化

PPT 工作室按“一句话生成，持续提意见”重做。入口只展示需求输入、可选资料和生成按钮，不再预先要求命名、选模型或逐项确认方案。助手自行构思方向和内容，仅在缺少必要事实时提问；回答后自动继续制作、检查、预览与导出。

成稿默认显示大预览、页面导航、修改意见和下载。选择页面或对象可限定修改范围，手工画布与详细方案按需展开。新修改产生新版本；升级前已有成稿的新修改意见同样自动更新预览与 PPTX，旧会话的精确重放保持兼容。聊天收起冗长历史回复并跟随最新内容，保留问题、错误和用户主动上翻的位置。

自动授权独立持久化，阶段交接不依赖浏览器；停止、恢复、版本冲突与输出失败均保持已有内容。自动期间禁止人工写入，停止后可以手改。预览与导出由程序统一绑定授权，防止停止遗漏输出作业。另修复相同页面 PNG 哈希相同导致的制品存储冲突。追加 V121，不修改历史迁移。
