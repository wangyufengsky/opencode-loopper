# 0.3.83 读路径、异步一致性与检测可观测性优化

基线：`f237f0d`（0.3.82）；本次只做本地交付。

## 优化目标与实现

| 目标 | 实现与验收 |
| --- | --- |
| 切换任务后 SSE 刷新可持续 | 独立订阅组件统一清理两个定时器及句柄，废弃旧订阅回调；刷新拒绝被受控捕获，后续事件可继续刷新 |
| 旧响应不覆盖新页面 | 筛选变化立即作废旧请求并清游标；分页绑定查询；overview/audit 按任务请求代次接收；overview 拒绝低版本；路由离开后不重新订阅 |
| overview 不读取大正文 | 专用 error/Judge 元数据 SQL，保留 task-scoped 正文读取入口及固定查询数 |
| 轮询成本与待处理记录相关 | Task 只选 RUNNING/JUDGING/STOPPING，独立远端清理保持；Automation 只选有 Task 的非终态 run，幂等键精确查找；500 条历史 + 1 条活动夹具只返回活动项 |
| 检测失败和恢复可见 | V76 独立健康表；最近检查/成功、连续失败、安全中文原因；版本比较拒绝旧配置结果；前端区分未检测/失败/恢复 |
| Git 检查并发有界 | 4 worker + 64 排队；同目录合并检查；完成后 5 秒缓存，最多 512 根目录；过载明确拒绝，shutdown 结清等待者 |
| 相关职责明确 | 抽出 taskEventSubscription、ProjectInspectionCache、AutomationMapper、MonitorReadMapper、AutomationPollHealthService，增加重点协作者构造依赖门禁；既有巨型 facade 上限未提高 |

结构目标采用本次读路径职责抽离，未对 DesignerSessionService/TaskService 做跨业务的大规模重写；其既有债务仍保留。
