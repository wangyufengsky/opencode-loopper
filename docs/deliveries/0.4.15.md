# 0.4.15 模板分析长度截断自动续接

新模板协议 V6 在精确请求的远端终态为 `length`、尚无已接受 MCP 候选时，在原 Session 中自动追加续接请求。沿用冻结证据、工具权限、模型及 Task/Attempt，不重做 Git 采集、不提高单次输出上限。V1–V5 按冻结行为恢复；V5 仍使用 MCP，但不自动追加长度续接。

V81 追加续接意图表，原请求、后续请求/哈希、不同内容提交计数与停滞计数和批次 DISPATCHING 检查点原子持久化。恢复先核对精确消息；同消息已送达不再发，未知或内容不一致不重发，明确不存在还须再次证明前一轮结束。当前轮询绑定新消息，旧 length 消息不能再次完成新轮。已有接受回执可避免未发送的续接，但仍必须证明远端停止。

连续三次长度耗尽且无新的不同内容 MCP 提交时，显示明确的停滞原因并停止自动续接。不同内容提交重置停滞计数；相同内容换键、幂等回放或思考文本变长不算进展。正常 MCP 修正次数不受该保护限制；既有任务时限、模型调用预算、身份/代际、取消与租约边界继续生效。任务删除显式清理续接记录，并与批次在同一事务回滚。
