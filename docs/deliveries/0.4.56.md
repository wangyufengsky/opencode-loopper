# 0.4.56 知识问答自主调查

本次按用户要求，将知识库 MCP 定位为可选工具，新增项目内原生只读调查，并在首次回答后自动自查和补齐调查。新建对话使用 contractVersion 3；历史对话保留冻结的角色、来源和权限。

## 行为

- 原生 `read`、`glob`、`grep` 与知识库、文档、Git、数据库工具可以自主组合；不要求先调用知识库或统一检索。原生 Todo 支持记录尚未完成的调查项。
- 调查提示要求沿必要调用链、配置、数据及测试核对事实，处理分页、截断、无命中与工具失败，不以询问是否继续代替已授权调查。
- 首次非空答案后，在同一 Session 内自动追加一次自查；仍有未完成 Todo 或待办投影不完整时继续。没有固定续查次数，但 Todo 与自查不能机械证明任何结论一定完整正确。
- V118 保存每次续查的独立消息身份、原请求及摘要、发送状态与思考前缀。未知投递只核对原消息，不盲目重发；停止保留原 Session 的停止证明要求。
- 原生调用与 MCP 调用共用工具展示栏，新增中文标签，保留默认折叠。原生读取可注明真实路径和行号，不要求为了引用再走 MCP。
- 新角色在知识 MCP 暂不可用时可以继续原生只读调查。保存满 100 条引用后仍返回读取结果，不用引用容量中断调查；请求超出文件末尾时返回现有行。
- 项目根、敏感文件和符号链接保护保持；本次不开放任意 shell、项目执行、文件或数据库写入及第三方 MCP。旧对话不追溯升级，使用新能力应新建对话。
