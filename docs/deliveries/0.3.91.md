# 0.3.91：收敛 Windows 发布回归

## 问题与修改

0.3.90 的 Linux、macOS 与 Release 构建通过，但较晚结束的 Windows 完整回归有两项失败（1560 项，2 失败，0 错误，16 条件跳过）。已将其 Release 标记为预发布，原标签和资产保持不变。0.3.89 的 Release 此前因 CRLF 测试夹具失败而取消，原标签保留。

- 证据准备在调用平台路径解析器前拒绝通配符。Windows 的 `*.java` 不再先抛 InvalidPathException 而误归为 UNCONFIRMED，统一返回 OUTSIDE_BOUNDED_SCOPE。仍禁止通配读取，保留路径包含、敏感文件、符号链接与字节上限保护。新增不存在根目录下的通配输入测试，证明拒绝发生在文件系统解析之前。
- Luna 无模型隔离测试验证真实 chmod 调用请求 0600，并核对复制内容。实际 POSIX 权限位仅在支持该语义的平台检查，避免将 Windows stat 的权限表示当作 POSIX 模式。运行脚本及真实 Provider 调用行为没有修改，本次不证明 Windows ACL 隔离能力。
- 沿用 0.3.89 的文档执行、确认门禁和输出路径修复，以及 0.3.90 的 LF/CRLF 发布工具夹具回归。
