## Windows CI 修正

- Word 受管二进制回执在 Windows 保存为反斜杠路径，严格文件读取器拒绝该内部路径。读取回执时统一分隔符，保持用户路径、作用域、符号链接和 SHA 校验；补充历史 Windows 回执幂等重放回归。
- 两份需求开发测试夹具固定 resources 3.5.0、compiler 3.15.0、surefire 3.5.6，匹配外层构建缓存；仍以离线 Maven 运行真实行为断言。新版测试在验证器失败时直接显示验证证据。
- 内置 JDBC 冷加载及 HTTP 重启测试改为独立 JVM，保留全部行为断言并确认进程退出后清理。第三方驱动与 SQLite 的 JVM 级句柄不再影响 Windows 临时目录清理；子进程超时、退出码与停止均有界检查。
- Windows 复验还发现 MCP 工具目录测试在子进程停止断言通过后，临时工作目录仍被占用。两个本地传输用例改为独立测试 JVM，继续在该 JVM 内断言 MCP 子进程已经停止；外层等待测试 JVM 退出后再清理目录。测试夹具类路径从实际编译位置取得，兼容聚焦与正式构建。三个聚焦用例通过，日志 `/private/tmp/loopper-028-mcp-child-focused.log`；本次追加修正仅涉及测试与交付说明，运行 JAR 未变。
