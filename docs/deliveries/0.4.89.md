# 0.4.89 Windows 回归修正与流程版本发布

## 范围

本版沿用 [0.4.88 的流程创作、需求规划与节点执行功能](0.4.88.md)，修复发布验证发现的 Windows 测试兼容问题。生产 Java、数据库迁移和流程产品行为没有修改；发布版本字段同步为 0.4.89。

- `OpenCodeRuntimeManagerTest` 的模拟可执行文件使用 `.exe` 后缀，符合 Windows 可执行文件解析规则；测试仍拦截实际进程启动。
- `DurableCommandsTest` 明确写入 UTF-8 字节，避免 Windows 标准输出默认编码影响中文校验。共享总时限用例把单次准备设为 2.4 秒、整体预算设为 4 秒，继续验证第一步成功、第二步耗尽共同预算、主命令未启动以及停止证明；不要求已被终止的第二个 JVM 一定进入 main 写入标记。
- `SourceTemplateMigrationTest` 的失败升级夹具显式持有并关闭物理 JDBC 连接，再读取旧记录。保留跨作用域历史 run 导致升级拒绝、旧数据不丢失的断言。没有跳过 Windows 临时目录清理，也没有修改 V129 等历史迁移。
- Windows CI 为每个测试类启用独立 Surefire JVM，释放跨类积累的 Spring、SQLite 和进程资源；全部前后端测试与完整 JAR 构建继续执行。
