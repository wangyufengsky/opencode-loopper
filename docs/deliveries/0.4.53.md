# 0.4.53 项目助手等待回复动态提示

## 变化

项目助手在模型未返回思考内容和正文时显示“正在思考”及三点动画，避免活动回合看起来没有响应。准备和发送阶段分别显示“正在准备回答”“正在发送问题”。提示由当前回合状态驱动，不生成思考内容、不估算进度、不修改模型配置或会话状态。

真实思考、回答正文或执行中的工具出现后，等待提示自动收起；工具完成且仍无思考/正文时恢复等待提示。待用户回答、回复投递中或结果未知、停止中、投递未知及终态均不显示等待动画。实际思考和工具记录继续独立折叠，用户展开选择不受更新影响。纯空白思考不显示空折叠框。动画只改变透明度与位移，遵守系统减少动态效果设置，状态文字对辅助技术可见。
