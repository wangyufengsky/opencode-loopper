# 0.4.77 角色管理导航、界面与工具展示

## 变更

角色管理移入“系统”一级导航，地址改为 `/roles`，旧 `/settings/roles` 自动跳转；设置页移除原入口。页面按工作流分组展示角色，采用目录与详情双栏、职责卡片、工具卡片和皮肤语义变量，兼容窄屏。

“概要”改为“描述”，展示角色职责、所属工作流及流程位置，保留当前绑定版本的查看入口。原生工具、精确 MCP 声明、服务端必需工具及程序内置工具统一放在“MCP”清单，标明来源；工具与权限名后追加中文用途，历史配置中的工具名也带说明。移除用户指出的两段冗长预览文案，仅保留简短配置状态及真正的项目/配置阻断原因。

缺失工具的根因是 BASELINE 角色的显式工具数组为空，旧页面主要展示配置数组，预览也仅补充必需候选工具，遗漏适配器和项目策略提供的工具。新展示复用既有权限编译结果，提取原生默认权限和精确内置工具并去重，不创建会话、不发现或调用第三方服务，也不修改实际授权、已保存策略或历史冻结配置。零工具角色仍为空；INTERSECT 收窄的能力不会由展示逻辑重新加入。
