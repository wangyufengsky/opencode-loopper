# 0.4.3 模板任务

状态：未交付候选。完整门禁因存量测试的迁移版本断言失败，未生成正式 JAR；后续人工复核又收紧报告缺陷归因规则，下一候选为 0.4.4。

## 行为变化

- 模板与自动化的新入口统一为内置模板任务，第一批支持代码审查、项目人员贡献周报，只有手动发起；历史模板、规则和任务记录保留，旧触发 API 停用。
- 使用版本化预制执行合同，参数直接实例化；每次不再调用 AI 设计。确认保持 PENDING_START，正式 Start 才准备独立目录和执行租约。
- 项目与分支为可搜索下拉框，分支默认主分支且可更改；日期控件默认北京时间最近七天，包含起止日，前后端校验结束日期不能早于开始日期。
- Git 证据在任务自有 bare 仓库同步，保留分支、提交范围、身份映射、合并与噪声处理依据。程序采集，模型分析，服务端校验覆盖和证据并渲染 Markdown。
- 代码审查生成完整报告；贡献任务生成总报告、个人报告和内置五维评分排名。权重为数量 30、代码价值 25、必要难度 15、质量与验证证据 20、工程维护 10；不以提交次数或原始行数替代全部贡献价值。
- 支持直接绑定故事；实际分析会话归 IMPLEMENTATION，程序步骤和缓存不虚构模型用量。报告内容最多两轮返修，同批双 Judge PASS 后自动完成。
- 页面提供报告版本选择、安全预览、Markdown 下载及同版本个人报告链接。报告发现代码缺陷或个人评分低，不导致报告任务本身失败。

## 运行范围与局限

模板任务需要 Java 21、Git 2.40+ 及可用的已配置 OpenCode 模型。模型资格验收使用 `opencode-go/deepseek-v4-flash`、OpenCode 1.18.23，在隔离的两人小仓库运行；正常样本必须无误报，植入的算术缺陷必须被定位。该结果不代表大型项目或任意模型的普遍成功率。

执行按所选分支可达提交的 committer 时间统计。浅克隆、octopus merge 和超限证据明确阻断；最终 Judge 提示沿用 128 KiB UTF-8 上限。敏感文件正文不交给模型，报告注明未审查。未知的 Git 或远端会话停止状态保持阻断和租约，不自动重叠执行。

评分为本项目的版本化观察标准，不是行业统一绩效制度，也不能推断未记录的评审、协作、工时和业务收益。研究来源及具体等级见 [执行记录](template-tasks-execution.md) 和 [功能合同](../seven-feature-contract.md#内置模板任务)。
