## 变更

- 为全部 39 个 SessionProfile、独立统计命令和 26 个内置角色声明能力；工作流知识、辅助工具及第三方 MCP 的授权不再依赖角色名称关键词或默认放行。

- 独立知识取证保留原有来源与引用边界；评审不能使用实时业务 SQL。新增能力收窄不能重新放开已被工具清单移除的原生工具，也不能绕过具体路径拒绝规则。
- 角色页面展示角色未授权、策略关闭、运行未就绪、待发现、待任务授权和配置待处理；保留关闭工具及原因，区分全局和项目策略，不把清单数量当作可用数量。
- 预览仍为纯读取，既不启动运行环境，也不注册工具或探测网络；阶段绑定修订与最新未激活修订保持区分。
