## 功能范围

- 新增流程库、模板创作与需求执行画布。支持自定义模板的创建、复制、修改、删除，预设模块与自由任务，拖动、缩放、连线、自动布局和撤销重做。
- 新需求从流程模板生成独立计划。支持单步、连续执行、运行至节点、人工检查点、条件分支、并行汇合、失败重试及暂停后修订后续节点。模型和程序生成的候选计划均需用户查看、确认后应用，应用不自动开始执行。
- 节点冻结角色版本、任务、输入和完成标准；交付物经过 MCP 候选、程序验证、接受和停止证明。文本、JSON、文档和代码拥有固定版本与来源，可供后继继续工作，移出计划不删除历史。
- 内置 45 项预设、12 条流程，覆盖默认开发、源码详细设计、单元测试、需求原文代码评审、知识整理、历史提交审查、贡献周报和全面/日期增量版本审查。自定义流程可移除业务评审；默认开发保留独立程序检查与双评审验收。
- 执行中流程另存模板可选择当前展开步骤或首次执行前结构，默认保留当前步骤；本次资料值与运行记录不会写入模板。
- 成果完成、人工认定和提交分别记录。已成功需求可明确选择固定成果，预览改动后进行本地提交、独立确认的远端推送或普通目录回填；保留并发保护、备份、停止及重启恢复。失败或取消需求的扩大提交资格仍待产品决定，当前不启用。
- 新建入口由需求任务承接原设计工作台、新建大型任务与需求开发模板；历史设计、任务、模板记录及冻结恢复继续保留。不新增强制独立流程规划师，现有角色可以承担规划工作。
- 补齐模型活动中的工具错误正文展示，拒绝原因优先于长参数，保持作用域凭证脱敏。

详细产品合同见 [流程合同](../workflow-contract.md)，实施和资格证据见 [阶段计划](workflow-goal-plan.md)及 [模块适配清单](../workflow-module-adapters.md)。
