# 0.4.63 本地交付：独立 PPT 工作室

状态：适用验收、完整门禁、正式 JAR 及本地服务更新通过；本任务内容经差异检查后创建本地提交。

## 功能范围

新增 `/ppt` 作品列表与 `/ppt/:id` 工作台，独立持有作品、阶段、版本、页面对象、资料、Agent 运行、制作作业与制品。提供七模块方案编辑、方向/制作两次确认、资料导入、单对象拖动/缩放/键盘移动、属性编辑、锁定、版本恢复、PNG 预览及可编辑 PPTX 导出。人工制作不依赖 Provider。

PPT_AGENT 使用受管 OpenCode 与 11 个专属私有 MCP 工具，权限绑定作品、run、Session、generation 和阶段。页面编辑采用原子批次、revision CAS 与幂等回执；人工修改不会被旧候选自动覆盖；停止未知保留 writer 阻断。统一页面模型由 POI 生成原生文本、图片、形状、表格、三类图表及嵌入工作簿，Java2D 负责测量与 PNG；Noto Sans CJK SC Regular/Bold 及许可证随 JAR 交付。

新增迁移 V119/V120；历史迁移保持原样。完整行为与限制见 [PPT 合同](../ppt-contract.md)，实施记录见 [开发账本](ppt-development-plan.md)。暂停期间保存与恢复过程见 [暂停交接](ppt-pause-2026-09-22.md)。
