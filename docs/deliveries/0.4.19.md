# 0.4.19 — 内网辅助 MCP 与执行反馈

日期：2026-09-13。基于 0.4.17，交付范围为本地源码、成品 JAR 和离线验收脚本。

## 行为与范围

- 独立辅助 MCP 提供九个结构化工具，受管 OpenCode 注入、loopback 传输、运行代际认证及 Session 作用域绑定；公开六工具与内部候选提交通道保持独立。
- 工具页增加全局默认和项目覆盖、版本冲突处理和系统必需工具保护。第三方 MCP 使用完整清单对应的精确工具授权，新发现工具默认停用；既有 Session 继续使用冻结策略。
- 数据库页支持连接创建、编辑、测试、启停、归档和多项目绑定。新增四个独立 JDBC 适配器及离线驱动清单，密码使用独立 AES-GCM 密文和主密钥。V82 为新 Task 冻结连接及凭据版本；旧任务不自动增加数据库授权。
- 数据库执行使用 JSqlParser 5.3 的保守 SELECT／WITH 子集、schema 和函数白名单、驱动只读设置、结果限额、有界执行器及取消机制。超时未实际结束的查询继续占用许可，不自动重发。
- 文档共享解析支持 DOCX、XLSX、PPTX、文本 PDF 和 Markdown，提供有界目录及分段读取、来源 SHA、解析版本和限制。旧附件继续读取原冻结表示；设计附件整体上下文保留既有 128 KiB 边界，大文档可从授权工作区分段读取。
- Word 从 Markdown 引用生成，必须有当前阶段明确登记且允许写入的 DOCX 路径。复用现有 Java 文档产物链，支持中文样式、表格和受管图片；输入身份、幂等回执、原子写入和用户修改保护保持独立于正式文档验收。
- 失败证据和当前合同通过 MCP 按引用读取；服务端在模型请求中附加工具及边界，自定义角色文案和重试模板不能删除必要约束。辅助调用的真实状态与产物引用进入既有任务活动、产物区域。

精确边界、离线驱动和密钥部署方法见 [辅助 MCP 合同](../assist-mcp-contract.md)。不增加数据库写入、网页 SQL 编辑器、OCR、Context7／RAG、在线驱动安装或报告手工 Word 导出。
