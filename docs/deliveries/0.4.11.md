# 0.4.11 模板统计停用与文档目录选择

## 变更

- 新模板任务暂不支持故事统计：移除表单开关、编号、能力探测及请求字段；创建事务不再建立 Story 绑定。旧页面开启统计的新请求返回 `TEMPLATE_STORY_ACCOUNTING_DISABLED`，不产生任务。
