# 0.3.92：内置 JDK 21 的六平台发行包

## 变更

- 正式 `verify.sh` 和 GitHub Release 共用六包组装入口：Linux amd64/arm64、Windows amd64/arm64、macOS Apple Silicon/Intel。
- 每包包含完整 Temurin JDK 21（保留许可证与 macOS Contents 布局）、正式 JAR、启动脚本、README 与来源/哈希元数据；同时保留独立 JAR，SHA256SUMS 覆盖所有发行资产。
- 启动器自动定位同目录 jdk21 与当前版本 JAR；支持路径空格和从其他工作目录启动，显式 LOOPPER_JAVA_HOME 仍可覆盖。macOS 入口为 start-macos.command，共用 Unix 逻辑，使用 open 打开浏览器。
- 固定六套 JDK 的官方 URL、大小和 SHA-256，下载缓存每次复核；校验解压版本/系统/架构、编译器、许可证和 JAR 内 SQLite 原生库。失败不发布部分发行目录，拒绝覆盖已有输出。
