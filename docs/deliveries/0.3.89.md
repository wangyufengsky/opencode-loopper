# 0.3.89：统一设计确认门禁与文档目标选择

## 问题与修改

0.3.88 的只读审计复现了三个问题：直接文档在需求讨论时可以调用创建任务接口；删除正文评审的规范可以保存，页面与服务端确认资格不一致；参考 README 位于最终交付路径之前时会被编译为输出。

- DesignerConfirmationGate 统一服务端读取、最终规范保存和创建任务的设计门禁；创建事务落库前再次检查，已确认草稿保持原任务幂等返回。进入总体确认、冻结画像、工作包批准及对应制品策略/计划分别校验。
- 文档仍由 Start 后的 OpenCode 撰写。删除正文 AI 评审的保存被拒绝，保留原草稿；旧版本无效草稿通过编辑器修复后可以恢复确认。冻结制品计划还必须属于当前设计和任务画像。
- 详情与概览返回 confirmationBlocker。保存后刷新服务端资格；刷新失败时保留已保存事实并阻断创建，提示重试保存。页面不再仅凭 COMPLETED 流程标志启用未确认任务。
- 文档目标解析区分明确输出、参考来源和可选改名。存在唯一明确输出时优先采用；多目标、格式冲突或越界路径返回可修正错误，未指定输出时使用已展示的默认文档路径。
