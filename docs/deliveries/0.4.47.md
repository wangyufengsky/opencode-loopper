## 行为变化

- 知识库立即显示页面与输入框。全局设置与项目、历史独立读取，模型目录在后台加载；目录慢或失败不阻断使用已配置默认模型发送。模型入口改为独立选择浮层，在其中显示其他模型的加载、失败和重试。历史会话进入不请求模型目录。默认模型的后端创建也不再执行额外 CLI 探测，其他模型继续校验。

- 回答上方新增思考与资料读取折叠条。活动回合显示转圈、思考或资料读取状态，用户主动收起不会被新内容重新展开；终态停止动画并收起，可重新查看。仅展示 Provider 已返回的本轮思考与真实工具记录，不推断或生成隐藏内容。Markdown 禁用外部图片并保持安全渲染，减少动态效果偏好生效。
- V115 追加思考正文，旧记录默认空值，历史答案保持原样。思考脱敏并限制为 64000 字符加截断提示，与回答一起受回合状态和版本 CAS 保护；采集错误不抹除已收到内容，停止后保留，下一轮不混入上一轮内容。
