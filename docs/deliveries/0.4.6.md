# 0.4.6 内置模板任务

本次把模板和自动化入口改为项目内置的手动模板任务，提供代码审查与项目人员贡献周报。版本化预制合同接收项目、分支、日期和可选故事绑定参数，服务端冻结后正式开始，不再为重复执行重新生成设计。

项目、分支支持搜索和分页，默认主分支；日期采用北京时间，默认最近七天，结束日期不得早于开始日期。程序在任务独立目录同步所选分支、冻结提交与证据；模型分批分析，服务端校验覆盖和依据、计算评分排名、渲染 Markdown，经过同批双评审后自动完成。内容最多返修两轮，失败和历史版本保留。贡献任务生成总报告及个人报告；评分标准和每项依据随报告输出。

旧定时、Webhook 和分支变化触发停用，历史数据保留。V77 支持全新数据库和历史升级。源仓库的当前分支、索引、提交和未提交文件不会因模板执行改变。

相较用户已收到的 0.4.4，补齐报告摘要中的中文名称、返修版本和哈希；模板详情移除普通任务设计入口与人工认定面板。同时明确模型响应必须逐字复制程序给定的身份字段，并在返修提示中带上服务端的具体校验错误；评分、身份校验和两轮返修上限保持原样。

## 运行与已知边界

需要 Java 21、Git 2.40+、可用 OpenCode 及内网可访问的模型配置。JAR 同目录执行 `java -jar opencode-loopper-0.4.6.jar`，默认地址 `http://127.0.0.1:8080/`、数据目录 `./data`。启动脚本为 `scripts/start-windows.bat` 和 `scripts/start-linux.sh`；升级前备份数据，V77 停用原自动化触发。

统计范围是所选分支可达提交的 committer 时间，不代表首次合入该分支的时间。贡献评分是本项目定义的可观察代码贡献评价，不是行业统一绩效标准，也不推测工时、业务收益、未记录的评审或未提交人员表现。浅历史、octopus merge 和超限证据明确阻断；最终 Judge 提示上限 128 KiB UTF-8，大范围需要拆分执行。

本次仅本地交付；未推送、发布、部署或替换既有服务。没有内置 JDK 平台包，未在内网、Windows/Linux 或真实故事统计系统执行验收。
