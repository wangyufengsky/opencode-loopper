# 0.4.35 — 冻结版本代码审查默认轻量化

## 变更

日期增量和全面代码审查的新建合同统一使用 `SNAPSHOT_CODE_REVIEW` V2。程序合并同文件小片段并以 48,000 字符 / 64 个片段的容量分批，文件头附着正文；不调用模型规划，不生成独立关系批次，不允许模型递归追加补充。关联代码可在本会话通过受控 MCP 按需读取。只有包含候选问题的分析批次创建一个复核 Session，同批问题一起复核；无问题结论不复核。

保留 SHA/blob/行号/原文引用凭据、完整覆盖校验、删除内容与排除原因、同会话修正、冻结预算、停止证明和手动失败重试。V1 输入中的新策略字段缺省且序列化时省略，旧快照/计划/会话及报告格式保持历史行为；旧任务不自动升级或取消。没有新增迁移，数据库版本仍为 111。贡献周报、历史提交审查和需求开发不改动。

页面显示准备范围、代码分析、问题复核与报告三个步骤，服务端投影轻量策略，报告明确无问题结论未经独立复核。正常成功路径 Session 数为 B + F（B 为固定分析批次，F 为有候选问题的批次，0 ≤ F ≤ B），失败重试另计。

方案来源及取舍见[轻量策略研究](snapshot-review-lightweight-research.md)，权威行为见[代码审查合同](../snapshot-code-review-contract.md)。
