# 0.4.9 模板任务界面与报告交付

## 变更

- 模板参数新增文档生成路径；登记项目和项目卡片支持默认文档路径，以版本校验保存。任务确认冻结目标目录，单次填写优先于项目默认，未配置时保留原任务目录。相对路径按项目根目录解析，各任务、报告版本在独立子目录内输出。
- 执行详情展示本轮代码分析、人员贡献的总批次、已完成和剩余数量，区分采集、分析、生成、校验与评审。新轮次不沿用旧计数，缓存命中按已验证批次计入；不预测未来返修或用分析百分比代表任务完成。
- 模板页改为可搜索、可分类的目录与参数区，支持后续新增目录条目；移除执行列表、时区与流程的重复提示。执行记录统一到任务页，以服务端任务类型筛选组合原有分页与其他筛选。
- 新增 V78 迁移。旧版模板合同、请求摘要和报告版本保持不变；旧活动任务可从冻结证据建立分析计划。
