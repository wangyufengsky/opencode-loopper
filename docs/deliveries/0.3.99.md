# 0.3.99：默认主页与 Skill 文档阅读

## 交付范围

两个需求合并为同一个版本。

- 根路径默认显示新主页；侧栏增加主页，品牌返回主页，未知前端路径回到主页；保留原有页面与任务深层链接。
- 首页沿用项目深蓝、青色、蓝色与紫色 token，使用内置 imagegen 生成视觉稿及轨道环插图。所有标题、按钮与卡片均由 Vue 渲染，插图随 JAR 静态资源离线打包。十个现有页面均有可跳转入口，无模拟统计或进度。
- 工具页分为“工具”和“Skill”分页。Skill 支持项目范围、名称/说明搜索、选择文档、Markdown 预览与源文、刷新和失败重试；项目切换与组件卸载拒绝迟到结果。
- 新增只读 Skill 清单/文档接口，按 OpenCode 实际发现的清单匹配名称。前端清单不包含正文，文档点击时读取；不接受文件路径，不打开本机任意文件。读取范围与上限见 [OpenCode 合同](../opencode-contract.md)。
- Markdown 正文来自 OpenCode 接口，源文视图保留接口正文；OpenCode 未提供的文件 frontmatter 不重建，不宣称与磁盘文件逐字节相同。预览复用既有安全 Markdown 组件。
- 主页不发起运行环境探测时，侧栏使用中性的“未检查”，避免永久显示红色“检查中”。

视觉稿、生成提示词和参考来源见 [主页设计说明](../design/home/README.md)。源文件为 `frontend/src/assets/home-orbit.png`，视觉稿为 `docs/design/home/concept.png`。
