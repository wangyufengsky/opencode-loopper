# 0.4.31 — 按 MCP-database 对齐数据库连接支持

## 改动

- GaussDB/openGauss 新建与明确编辑采用 MCP-database 成品中的 openGauss JDBC 3.1.0，驱动类 `org.postgresql.Driver`，连接协议 `jdbc:postgresql://`。两个产品拥有独立不可变 profile；历史 6.0.3、7.0.0-RC3-og 与冻结任务保持原驱动。
- 开放 GaussDB 新建、编辑、项目绑定、测试、筛选与冻结配置；新增 Oracle Thin（ojdbc11 23.7.0.25.01）、DB2 Type 4（jcc 12.1.0.0）。保留现有 MySQL、达梦及独立 openGauss，覆盖 MCP-database 的五类产品。
- Oracle 支持服务名与 SID URL；DB2 支持标准远程 URL 及受控属性段。凭据独立传递，URL 属性仍经白名单校验，不能绕过只读、超时或本地文件保护。
- 新增 Oracle 只读事务及 Oracle/DB2 schema、超时、离线探针适配。保持隔离驱动加载、原始 JAR/SHA 校验、SQL AST 检查、返回行数上限和历史凭据版本。
