# 0.4.90 Windows 全量回归修正

## 范围与发现

继承 [0.4.88 流程功能](0.4.88.md) 和 [0.4.89 的 Windows 夹具修正](0.4.89.md)。0.4.89 尚未发布，扩大 Windows 验证后发现额外产品问题，按候选版本规则顺延为 0.4.90。

- 项目取消管理后重新注册，可能读取旧的技术栈画像。旧查询依赖时间字符串和随机 ID 排序；相同时间、不同时间精度都不能可靠表示保存顺序。V191 追加画像顺序字段和索引，在 INSERT 内分配顺序号，详情及列表统一读取最新已保存画像。历史画像正文、ID 和冻结引用保持，V42 等旧迁移不修改。
- 源码分批的目录标题原先通过宿主 Path 转换，Windows 将固定清单的 `src/feature` 变成 `src\feature`。改为直接划分固定清单的 `/` 路径，同一清单生成一致的目录标题，覆盖范围和文件顺序不变。
- Windows runner 的进程启动异常仍在独立诊断中；不能把 JVM 分类隔离当作已验证的基础设施修复。
