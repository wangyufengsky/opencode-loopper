# 0.4.84 工作流、角色提示与权限一致性

## 变更

- 模板报告与源码快照的跨任务复用校验完整冻结角色摘要。拥有可变项目知识来源，或数据库、文档、任务证据等其他动态资料能力时绕过复用；缺少角色快照的历史流程也不命中缓存。保留历史批次身份、冻结输入、已经接受的结果及恢复入口。
- 模板分析按文本或 MCP 通道直接组装，不对完整提示做字符串删除/替换。初次提交与续接片段统一从任务冻结角色读取；源码快照角色补齐共享协议片段的冻结清单。
- 分解、评审、模板、规范、编译及收尾提示以实际授权的工具为边界，消除禁止合法辅助读取或误称零工具阶段仍可使用 MCP 的指令。知识降级只列出持久化权限和当前请求允许的原生读取工具。
- Judge 补充知识引用放在单行 reason 的“补充背景”，先通过同会话引用回读核对。正式 evidenceIds 继续严格限定冻结目录，不把知识查询当作执行验收成功；未增加未经验证的正式证据字段。
- PPT 的可配置 ppt.base 纳入冻结请求，恢复使用原请求。全局 Agent 仅保留固定的权限、锁定、凭证与保存/导出边界。
- 角色页的模板流程修正为确认参数、开始执行、冻结证据、分析并提交候选、校验与生成报告；源码快照明确问题独立复核节点。

- 升级导入以当前内置槽位归属表接受新增片段；原样导入已有修订时保留原片段集合及内容哈希。升级激活不改变旧流程冻结，跨槽位提示仍拒绝。
