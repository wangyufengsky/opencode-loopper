# 0.4.8 Git 2.30.2 兼容与固定报告格式

## 变更

- 模板采集以 Git 2.30.2 为最低基线：全历史遍历后筛选时间，独立 index 读取历史属性，独立临时目录重建递归合并基线；不再依赖 `--since-as-filter`、`check-attr --source`、`--remerge-diff`。
- Git 启动前检查版本，失败按参数、认证、网络、仓库和文件读写分类，展示操作与退出码；不持久化原始 stderr 和可能的凭据。WAITING_INPUT 的页面标题按实际等待状态展示。
- 新任务模板版本 2：代码审查、项目贡献总报告、个人贡献周报的 Markdown 章节与表格固定；正文和 SHA-256 随任务冻结。旧合同使用保留的 V1 渲染器，已生成报告保持不变。
- 总报告与个人报告都包含五维得分、理由与证据；个人覆盖数只统计自己的关联提交。评分仍为 CONTRIBUTION_SCORE_V1（30/25/15/20/10），本次未修改算法。
- 无数据库迁移，无项目原目录 checkout、index、分支、提交或推送变更。格式和虚构示例见[固定报告格式](../template-report-format.md)。

## 运行与交付边界

运行需要 Java 21、Git 2.30.2 或更高版本、可用 OpenCode 与内网模型配置。JAR 放在原有启动目录并沿用现有配置与数据目录，启动命令为 `java -jar opencode-loopper-0.4.8.jar`。Linux/Windows 启动脚本位于 `scripts/start-linux.sh` 与 `scripts/start-windows.bat`。本次未自动替换或重启已有服务。

升级后新发起的模板任务使用固定 V2 格式；旧任务与既有报告保留。本机旧 Git 兼容证据不等同于内网 Windows/Linux 真机验收；本轮未追加真实模型付费调用，分析协议和评分算法沿用此前实现。浅历史、多父合并、超量证据等原有完整性边界仍保留。
