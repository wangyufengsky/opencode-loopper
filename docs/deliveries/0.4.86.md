# 0.4.86 知识工具与文件定位

## 范围

- 新增项目概览、历史证据目录、批量原文读取、符号词法候选、固定 Git 版本正文检索、历史差异正文检索和版本比较，共 7 个工具；辅助工具目录合计 40 个。
- 目录支持深度、类型、扩展名和路径模式；结果返回后续浏览/读取参数。统一及单来源搜索支持逐条正文命中，并保持查询/拥有者/版本绑定、分页和不完整覆盖信息。
- 知识问答可回读本会话 `knowledge:` 历史证据；业务角色仍使用独立 `call:` 证据。批量读取逐项处理失败和引用；目录/概览保存采集时元数据，界面可查看。
- MCP 支持来源内 `./src/...` 和 `.` 根目录；拒绝所有 `..`、绝对路径、受保护文件及符号链接。来源返回路径基准，错误提示区分路径和文件问题。
- 默认文件模式查询 `xxx.java` 等文件名时，代码来源先按目录递归定位同名文件，再返回每个文件的内容片段、路径、SHA 和原文指引。查正文中的文件名提及使用 occurrences。
- 新工具遵守现有角色能力、全局/项目开关和冻结工具快照；历史会话不追补授权。PPT 复用目录筛选与逐条检索，保持自己的证据归属。
