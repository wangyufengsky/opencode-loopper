# 0.4.52 本地交付：知识库第二版

落实第二版的 8 项交互优化与 4 项新增功能；当前用户确认优先：右侧引用使用可调宽的悬浮抽屉，正文宽度、位置和滚动不变。行为定义见 [知识库合同](../knowledge-contract.md)。

## 交互与功能

| 需求 | 本次结果 |
| --- | --- |
| 思考与工具调用分开 | 两个独立折叠条，默认收起，各显示最新内容；没有思考时不显示等待占位，等待用户时停止工具动画 |
| 引用范围高亮 | 校验并支持 `#L10-L15` / `#R2-R5`；代码、文档行号和数据库行高亮，文档阅读视图高亮对应块 |
| 来源面板重设计 | 代码、文档、Git、数据库分类，状态、统一检索及同一文件分段去重 |
| 去掉占位与冗长说明 | 删除思考等待文案、冻结配置页脚和通用提取限制文案；实际读取错误仍显示 |
| Token 图标 | 输入区图标展开输入、输出及合计；服务端累计高水位，未知值不伪造 |
| 正文不被引用面板挤动 | 右侧覆盖面板、拖动与键盘调宽、保存宽度；打开期间暂停自动滚到底部，关闭恢复焦点 |
| 顶部缩短 | 单行紧凑导航，包含项目、新建、历史、来源和项目管理 |
| Git 来源与 MCP | 自动识别仓库，6 个只读工具查询引用、作者、提交、差异、历史文件与 blame；支持合并提交父版本差异，限定当前项目子目录 |
| 历史面板 | 独立路由，项目/关键词/时间/状态/归档筛选、稳定游标、归档恢复及对话进入；返回保留草稿与历史列表位置 |
| 助手提问 | 新会话按能力冻结原生 question 权限；单选、多选、自定义回复、持久化幂等投递及刷新恢复；旧会话保持原权限 |
| documentPath | 项目文档目录自动成为新会话来源；不可读明确显示，修改项目配置不替换历史冻结路径 |

Git 只查询本地已知记录，不自动 fetch；查询冻结引用和分页快照，最多扫描 1000 个提交并标记不完整。作者与提交者时间分别提供，“昨天”以会话浏览器时区解释。合并提交、敏感路径、符号链接、子目录隔离均有回归。资料和工具内容仍按不可信数据处理。

V117 追加会话选项、提问回执和 Git 快照；旧会话使用合同版本 1，新会话使用版本 2。归档不停止业务、不删除证据；未确认的回答投递不会自动重发，用户可停止该轮后继续。
