# 0.4.2：按统计事件打开弹窗，停止空闲轮询

## 行为与边界

- 统计弹窗保留全局挂载，通过 `/api/story-accounting/events` 等待统计变化。订阅建立（含重连）后读取一次未关闭调用列表，空闲时不再每 1.2 秒查询列表。
- 后端复用既有尽力投递与 SSE 生命周期机制；开始、取消中、终态、重启恢复及关闭回执通知前端。start 失败后的 continue、后台 complete 与手动 retry 经过同一个执行入口。事件不改变业务或统计结果，事务回滚不发布事件。
- 仅当前选中的 PREPARED/CANCELLING 调用每 1.2 秒刷新详情；结束后保留回执并停止刷新。并行统计中当前调用结束时，立即选择仍在进行的调用，不再依赖下一轮列表轮询。页面隐藏时暂停查询，恢复可见后补查。查询中到达的事件合并补查；恢复查询失败最多延迟重试三次，后续事件/重连可以重新恢复。详情失败不会重新开启列表轮询。
- SSE 每 25 秒发送保活注释，不查询数据库、不触发前端列表刷新、不调用模型。连接断开清理对应订阅，其他订阅和业务继续。
- 未改动数据库迁移、统计命令次数、手动取消/重试授权、业务会话及入账语义。
