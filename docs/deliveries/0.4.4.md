## 内网运行

需要 Java 21、Git 2.40+、可用 OpenCode 及内网可访问的模型配置。在 JAR 所在目录执行：

```sh
java -jar opencode-loopper-0.4.4.jar
```

默认页面 `http://127.0.0.1:8080/`，默认数据目录 `./data`。升级前备份原数据；V77 会停用旧自动化触发，历史任务和记录保留。报告按所选分支可达提交的 committer 时间统计，浅历史、octopus merge 和超限证据明确阻断，最终 Judge 提示上限 128 KiB UTF-8。

本次未推送、发布、部署或替换既有服务；未制作内置 JDK 平台包，未在内网、Windows/Linux 或真实故事统计系统进行验收。
