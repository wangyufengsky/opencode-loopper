# 0.4.54 — 可选的知识库统一检索

## 交付范围

新增 `search_project_knowledge` MCP 与共用的 HTTP 查询服务，检索当前授权的代码、文档和数据库结构。AI 自主选择工具，可以直接调用原有单来源、Git、原文或只读数据库工具，也可以在统一搜索后补充查询与交叉核对；没有强制先调用统一搜索的路由。旧远端 Session 的权限快照保持，新建对话取得新增工具。

支持原词、原句空白/中文换行、字段命名变体和显式扩展词线索。结果按已扫描批次排序、按文件版本和位置去重，附带原文读取参数；搜索本身不生成引用。数据库只查授权 schema 的表、字段、注释，Git 历史使用既有专用工具。每个来源独立报告未查、待续、完成、受限、失败或超时，分页身份绑定查询与授权。边界见 [知识库合同](../knowledge-contract.md#统一检索第一版)。

来源面板使用同一服务，提供搜索模式与来源范围选择，搜索后优先展示结果和覆盖情况，可以返回资料列表。文件命中按 SHA 读取原文；字段命中打开数据库结构。切换条件/项目丢弃迟到响应，数据库结构没有下一页时不显示无效按钮。原有等待动画及思考、回答、工具状态保留。

没有新增第三方依赖、数据库迁移、外部服务、向量数据库或 embedding 模型。
