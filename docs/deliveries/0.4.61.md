# 0.4.61 spdb风皮肤

## 范围

新增名为 `spdb风` 的皮肤，ID 为 `spdb`，参考浦发银行官网的蓝、红、白组合，采用深蓝主操作、红色强调、白色与浅蓝灰表面。配色依据、建筑来源及完整生成提示词见[设计记录](../design/spdb-skin.md)。

- 新增浦发银行相关的原创主页插画：外滩 12 号建筑意象、上海天际线，以及 Loopper 的规范设计、分支开发、双评审和交付证据回环。
- 设为默认皮肤；无选择、非法保存值及存储不可用时使用 spdb。历史有效的手动选择继续保留，同源标签页同步行为不变。
- 继续通过统一配置扩展，无具体皮肤的页面分支。增加可选桌面图片右侧留白配置，让新构图完整呈现；原两套皮肤维持原值。
- 首屏初始化明确按默认 ID 兜底，不再隐含依赖注册表第一项。皮肤选择器自动显示三套配置。
