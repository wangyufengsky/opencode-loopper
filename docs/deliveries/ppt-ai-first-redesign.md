## 已确定合同

- 新入口只需需求正文，附件可选；名称初始化、系统模型、设计方向由程序与助手处理。
- 一次“生成 PPT”授权覆盖方案、制作、预览与导出，不再要求两次方向/设计确认。
- 缺失关键事实时可提问；回答后继续。生成后每条修改意见作为独立授权，保留历史版本并更新 PNG 与 PPTX。
- 后台持久化授权与阶段交接，不依赖页面停留；停止撤销后续派发，身份未知继续阻断。
- 制作后默认展示预览和对话，人工画布与详细方案由用户选择展开。
- 权威定义见 [PPT 合同](../ppt-contract.md)，追加迁移 V121，历史 V119/V120 不修改。

## 开发中发现与集中修复

- 相同页面生成相同 PNG 哈希时，旧存储路径触发作业内唯一约束；路径加入稳定制品 ID，内容哈希仍用于完整性校验，历史路径继续可读。
- 输出作业创建与自动授权绑定改为同一短事务，停止不能遗漏中间状态；自动模型不自行创建第二套输出作业。
- 自动授权未结束时，人工编辑在服务端事务内阻断；停止后可手改并基于新版本显式恢复。
- 问题答案进入跨阶段冻结上下文，长需求加长回答不再被拼接成超长的单次输入。
- 第一轮真实模型暴露稳定角色提示与自动 run 提示冲突：自动文件已生成，聊天仍要求确认导出。稳定提示收敛为共同边界，阶段行为由冻结 run 决定；用户回复改为简短中文，真实模型复验后记录正式证据。
