# 0.4.66 — PPT 项目资料与需求沟通

PPT 新建入口增加可搜索、分页的项目选择。选择项目后，以作品独立保存创建时可用的知识来源，PPT 助手可检索、浏览、读取文件和 Git，以及查询该项目绑定的只读数据库。读取保留作品所属的不可变证据，后续方案可引用并重新读取原证据；不借用知识库会话、不开放其他项目或通配 MCP。

新作品输入要求后点击“开始沟通”。助手逐轮澄清内容重点和设计偏好，汇总后由用户点击“确认需求，开始设计”，才自动完成方案、制作、预览和导出。普通回答、模型最终文本均不能代替确认；补充意见使旧确认失效。成稿后的对话修改保持直接执行，手动编辑仍为生成后的可选入口。旧作品、旧授权和回执继续按冻结协议处理。

追加 V123 保存问题类型和明确确认，V124 保存项目来源与证据。多轮提示增加仅出站可见的当前身份通知，保持 Loopper 持久请求不含调用凭证；旧轮次不授权执行。受管 PPT 的精确恢复先完整验证通知，再严格校验业务正文与附件，其他角色不使用该处理。
