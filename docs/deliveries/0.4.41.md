# 0.4.41 — SQL Server 与连接管理界面

本次完成五项请求：新增 SQL Server 内置驱动，明确 GitLab HTTP 配置入口，延长并加宽模板任务目录，重做数据库连接后的管理工作区，合并项目 Git 账号与 GitLab 管理入口。

## 实现

- SQL Server：内置 Microsoft JDBC `13.4.0.jre11`，固定 SHA、离线提取与隔离加载；支持 `jdbc:sqlserver://host:1433;databaseName=app` 及受控 TLS 参数。凭据仍单独加密保存，原有数据库配置和冻结驱动身份保持兼容。
- SQL Server 不支持 JDBC `setReadOnly`；新增有界有效权限检查，拒绝写入、执行和管理权限；维持 SQL AST 校验、明确 schema、非自动提交、回滚及查询限额。测试结果区分 JDBC 标记与权限检查，结构读取同时限定 catalog 和 schema。
- GitLab：现有设置、Git 账号、读取适配器已支持 HTTP；本次明确 HTTP/HTTPS 输入及 HTTP 状态提示，回归覆盖明文 HTTP 的本地服务器、禁止重定向与实例匹配。项目只显示“Git 与 GitLab”，窗口内分别管理账号和 GitLab 仓库/证据，保留原来的独立凭据与权限边界。
- 模板任务：桌面目录宽度上限由 340px 调整到 420px，最小高度 720px，并随右侧区域拉长；移除原 560px 列表高度限制，窄屏自然排列。
- 数据库管理：连接目录与详情工作区，集中显示地址、账号、驱动、授权项目、schema、限额及逐连接测试结果。覆盖加载、空列表、失败重试、停用、归档和窄屏状态；刷新丢弃过期测试结果。
