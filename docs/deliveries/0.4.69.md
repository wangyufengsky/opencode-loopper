# 0.4.69 — PPT 制作故障恢复与流程优化

本次针对 0.4.68 PPT 流程审查集中修复。内网 Windows 截图的具体 Provider 错误没有运行日志，不能据此认定为输出截断；新版本保留脱敏错误类别、错误码、详情及停止证明，方便今后精确诊断。

## 行为变化

- 新授权对已证明停止的输出截断、限流及临时服务故障持久化自动恢复；2/8/30 秒退避，连续三次无内容进展后保留结果等待手动继续。用户停止、未知投递、配置权限错误与版本冲突不会盲重发。累计输出安全上限也先取得停止证明，再进入恢复。
- 正常模型终态后，缺页/空页/布局等失败形成页面检查点并交回模型修复；保留通过页，范围外阻断不自动扩大授权。
- 讨论与确认统一容量，累计冻结文本超过 24000 字通过有界分段读取，原文完整保存；上限 100 万字，确认前预检。
- 输出作业重试统一续接当前生成授权，已成功预览可复用并继续导出；暂停/失败支持“按当前要求继续”和“调整要求并继续”，新要求冻结为新授权，保留旧记录与范围；输出重试绑定原授权，补充问答保留已确认需求。
- 新 MCP 协议压缩写回执，兑现按页检查；新增语义内容块排版并在创建前测量，过密返回问题且不截断文字；前端纯活动事件减少整份页面下载，显示恢复与版本对应的检查进度。
- V126 为新授权恢复与模型错误追加表，旧授权不隐式启用新策略；显式恢复后启用。
