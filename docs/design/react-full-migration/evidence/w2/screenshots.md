# W2：真实 React 生产页面桌面截图

**58 张实际 Chromium 截图，全部使用模拟数据。** 入口为本批生产构建后的真实 SPA 路由，不是 W1 预览、设计 HTML 或旧 Vue 页面。GitHub 可显示 PNG/Markdown；本次仅本地提交，尚未发布。

42 张默认主画面＝14 路由×三皮肤；另 14 张选中状态、PPT UNKNOWN 和 Settings dirty 各一张。默认图 1440×1000，选中图 1280×900；另两张阻断状态采用浏览器桌面默认尺寸，准确尺寸/哈希见 [验证清单](verification.json)。每图最后两次采样完整 PNG SHA 必须相等，无像素容差。

## 当前阻断必须可见

PPT 原制作要求 UNKNOWN：原正文只读、原 metadata 和唯一 POST 身份不因三皮肤切换而变。

![浦发 · PPT UNKNOWN · 模拟数据](screenshots/spdb-ppt-unknown.png)
