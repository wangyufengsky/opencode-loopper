# W3 三皮肤生产页面截图

**实际 Chromium 生产 SPA 渲染＋本地模拟 HTTP/SSE／数据，桌面限定。** 不是设计原型；未调用真实 Java 后端、模型、文件解析或 PPTX 生成器。PPT 默认图片由浏览器 Canvas 按同一模拟 deck DTO 绘制，选中图是既有 React 自由对象编辑器。

最终构建后重新捕获的 33 张 PNG；每张两次连续原始 PNG buffer 完全相同。文件尺寸／SHA 见 [screenshots.json](screenshots.json)，行为及严格退出证据见 [W3 报告](README.md)。文档／源码已选状态截图保留真实桌面首屏，长报告详情可在页面向下阅读，不把截图当全部内容的覆盖证明。
