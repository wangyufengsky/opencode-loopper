# 项目知识库合同

知识库是独立的单项目问答入口，只存在用户与 AI 的对话。它不创建 Designer、Task、Stage、Judge，不申请任务队列或工作区写入租约，不执行文件生成、代码修改或数据库写入。

## 界面与会话

- `/knowledge` 为聊天默认页，`/knowledge/:conversationId` 打开历史。项目、系统默认模型及资料选择在首次发送前可调整；会话创建后固定，调整配置通过新对话完成。
- 新对话从全局设置的 `provider` 与 `model` 组装完整模型标识，不根据裸模型名猜测提供方。页面和输入框立即显示，全局设置、项目与历史独立读取；模型目录在后台加载，不阻断页面、历史或使用已配置默认模型发送。默认模型创建不重复执行 CLI 目录探测；显式选择其他模型仍由服务端核验。点击模型入口在选择器内展示加载、失败与重试；列表失败不影响默认模型。尚未配置全局默认时可手动选择目录中的已配置模型；全局配置读取失败阻止新对话发送并提供恢复入口；重新读取保留草稿、显式选择和已有会话的冻结模型。
- 顶部使用 56px 左右的单行工具栏，项目选择、新建对话、历史对话、来源与项目管理并排。项目管理入口定位当前项目；窄屏保留可访问名称并收敛按钮标签。
- 默认来源与引用面板均收起。来源展开左侧，回答引用展开右侧；两者均为覆盖面板，不参与聊天布局。右侧默认 480px，支持指针拖动、方向键、Home/End 与双击复位，并记住像素宽度；桌面限幅 320px 至工作区的 85%（最大 1000px）。低于 1100px 互斥并使用模态抽屉、Esc、焦点约束及关闭后焦点返回。打开、切换、关闭、拖动引用抽屉必须保持正文宽度、位置与滚动不变；引用开启期间暂停聊天自动滚到底部。
- 左侧来源按代码、文档、Git、数据库分组，提供类别筛选、状态及统一文件检索。检索同一 canonical 文件和分段的结果去重；只返回已勾选或会话冻结的来源，受单来源扫描上限约束。读取失败显示原因和恢复入口，不以空列表冒充成功。
- 思考、工具调用各自独立，初次默认收起；折叠条仅显示最新思考段和最新调用摘要，展开保留本轮真实记录（工具最多展示最近 30 条）。只展示 Provider 返回内容，不生成或推断隐藏思考；没有思考时不显示空的思考折叠框。模型尚未返回思考或正文且没有工具正在执行时，项目助手显示独立的三点动态等待提示：准备阶段为“正在准备回答”、发送阶段为“正在发送问题”、运行阶段为“正在思考”。提示仅表达当前回合的等待状态，不生成思考内容或估算进度；出现真实思考、正文或执行中的工具后切换为对应内容，等待用户（含回复投递中或结果未知）、停止、失败与终态不显示等待动画。用户展开状态在流式更新时保留。工具动画仅用于真实执行中的调用，所有动画尊重减少动态效果设置。
- 删除冻结配置说明、正文下累计用量文字与泛化的文档提取限制文案。输入区用 Token 图标展示会话累计输入、输出与合计；数据取服务端累计最大值，刷新、历史分页或旧快照不使其降低，缺失保持未知，不估算价格、不合并任务统计。真正的解析失败或截断原因仍需可见。
- `/knowledge/history` 为独立页面，按今天、昨天、更早分组；服务端支持项目、标题/正文关键词、时间、状态及归档过滤，最近活动时间加 ID 游标分页。归档只改变组织元数据，不停止模型、不删证据；恢复与归档要求版本 CAS。历史页保留筛选、已加载页与滚动位置（恢复最多前 20 页）；返回对话保留未发送草稿并重建 SSE 订阅。
- 来源配置属于项目，旧会话保持原冻结授权；移除绑定不删原文件或历史证据。Markdown 沿用安全渲染，知识正文与证据不自动加载外部图片。

## 服务端权威及恢复

V114 追加会话、回合、来源、引用及调用记录；V117 追加会话组织/时区/交互合同、待回答问题与 Git 查询快照表，旧会话 contractVersion=1、新会话=2，保留旧执行身份和答案；V115 为回合追加独立思考文本，旧记录默认为空，不回填或重写旧答案。思考仅采集精确用户消息对应的 Provider 片段，脱敏后累计最多 64000 字符并提示截断，与实时回答一起受回合版本及 RUNNING 状态 CAS 保护。采集异常不改变问答状态、不抹去已有内容；停止和终态保留已采集内容。`KnowledgePersistence` 使用既有生命周期服务和短事务提交会话/回合的 CAS 与审计。文件、数据库、模型请求均在事务外。

会话只有一个活动回合，由数据库唯一约束及持久化幂等键保护。回合在网络发送前保存准确的用户消息身份、请求和摘要；会话创建保存完整创建计划。创建结果或发送结果未知时仅查询原身份，不重复派发。停止必须有明确 abort 确认或准确不存在证明；未确认时继续阻断下一轮。进程重启重新扫描活动回合，运行代次不匹配时保持阻断并提示检查环境，不把新代次冒充旧会话。

`KNOWLEDGE_CONVERSATION` 与 `KNOWLEDGE_TURN` 为独立状态机。REST 返回权威状态，SSE 仅发布失效事件；客户端断线重连时回读。正文按消息分页，引用正文首次打开时读取。订阅故障不改变模型状态；重启前未完成的资料调用标记结果待核对。

## 来源、检索与证据

- 代码读取项目当前本地目录，含未提交改动。范围为登记的项目根，禁止扩展到兄弟目录；排除隐藏敏感路径、密钥、依赖及构建目录，拒绝符号链接越界。读取有文件大小、行片段及响应边界。
- 项目的 `documentPath` 自动作为“项目文档目录”来源纳入新会话默认选择。不存在或不可读时显示不可用原因，不擅自创建目录；修改项目配置只影响新会话，历史会话继续使用旧路径快照及 containment 校验。
- 文档支持 Markdown、DOCX、XLSX、PPTX、文本 PDF；项目文档、登记的外部文档目录和上传文件分别授权。扫描 PDF 不做 OCR。SHA + 格式 + 解析器版本缓存分段，缓存不授予访问权限。
- 上传每批最多 10 份、单文件 20 MiB、总计 50 MiB。先记录 PREPARED，写入受管数据目录临时文件并原子完成；重启后按内容哈希恢复。重复文件复用已有绑定，单个解析失败不阻断其他文件。移除不删原件。
- 路径及字面关键词检索支持中文短词。目录分页每页 50 项，单次扫描最多 4096 项、深度 12；到达边界明确报告不完整并要求缩小范围。代码单文件最多 1 MiB，每次最多 200 行 / 12000 字符；文档每次读取一段，目录分页 100 段。缓存最多 64 份 / 400 万字符，解析并发和等待有界。无命中不证明不存在。
- 每次实际原文/数据库读取保存独立证据 ID、来源、位置、SHA、采集时间和正文。同轮文件变化产生新证据并标记变化，旧证据不覆盖。每回合最多保存 100 条证据，达到上限明确提示在后续回合继续。
- 回答中的 `knowledge:` 链接仅允许本会话已读取的真实 ID。可带 `#L10-L15` 或数据库 `#R2-R5` 范围；服务端集合查询校验范围属于保存证据，越界或单位错误降级未核实。代码/Markdown 对应原文件行号，Office/PDF 对应当前解析段的文本行号，数据库对应本次结果集行号。右侧默认带行号显示并高亮/定位命中；文档阅读视图高亮相应 Markdown 块，数据库提供表格行高亮与原始结果切换。伪造引用降级为未核实文本；引用正文查询再次校验会话归属。历史展示保存片段，不读取当前文件替代。
- 数据库复用项目绑定、加密凭据引用、schema 限制、SQL AST 只读检查、超时及结果限额。查询结果记录时间、SQL、截断信息；界面只展示结构和结果，不提供 SQL 执行入口。

## 运行与权限

首版发送仅支持受管 OpenCode；外部 auto/http 模式可管理资料和查看历史。`KNOWLEDGE_READ_ONLY` 基础权限 deny-all；新会话探测到原生 question 能力时冻结为 `KNOWLEDGE_INTERACTIVE_READ_ONLY`，只额外允许原生 question。未提供能力时保持文字澄清，等待用户下一轮回答。两个知识角色仅精确开放以下辅助 MCP：

- `list_knowledge_sources`、`browse_knowledge_source`、`search_knowledge`、`read_knowledge_source`。
- `list_database_connections`、`inspect_database_schema`、`query_database_readonly`。
- `inspect_knowledge_git`、`list_knowledge_git_authors`、`search_knowledge_git_commits`、`read_knowledge_git_commit`、`read_knowledge_git_file`、`blame_knowledge_git_lines`。

工具凭证在传输时注入，校验运行代次、知识会话所有者、当前活动回合、项目目录及冻结来源。其他任务角色不能使用知识工具；知识角色不能使用 shell、原生文件工具、候选提交、Word 或第三方 MCP。资料及数据库内容均为不可信数据。知识问答免固定 agentic 步数、Task 尝试次数及 Designer 总预算；单次网络、读取、解析和数据库查询边界仍适用。

首次创建与精确恢复远端 Session 共用运行身份及辅助权限快照登记；登记完成后才能把 Session 交给知识会话。知识问题在传输前必须取得与冻结角色一致的有效作用域，并确认辅助 MCP 在线；明确发生在模型请求发出前的授权/连接拒绝将该回合标记失败并恢复可操作状态，不作为投递未知，不派发无凭证问题。实际请求已发出后的网络异常仍按未知投递恢复，不能凭通用错误推定未发送。

## Git 来源及可追溯查询

自动识别登记项目所属本地 Git 仓库（含仓库子目录）；新会话冻结仓库身份和项目范围。Git 与当前本地代码是独立来源，Git 来源不能借用通用文件工具读取未提交内容。MCP 与左侧浏览器共用只读实现，提供本地引用、作者、提交筛选、差异、历史文件及逐行最后修改记录；不执行 fetch、checkout、hook、外部 diff、textconv、shell 或延迟远端取对象。敏感路径、符号链接、兄弟目录拒绝读取。

查询使用本地分支、远程跟踪引用和标签（最多 128 个），默认作者时间，可明确选择提交者时间；返回作者/邮箱/作者时间与提交者/邮箱/提交时间。新对话冻结浏览器 IANA 时区，派发提示给出当前时间与“昨天”的当地零点半开区间；用户明确日期和时区时按其要求。姓名歧义先列出邮箱/作者供澄清；零提交不能解释为没有工作，最后修改记录不能当作问题引入者证明。

每次扫描最多 1000 条提交、每页 50 条，超过范围明确标记不完整。首次查询保存引用 SHA 与结果快照；后续游标绑定所有者与筛选条件，新提交不会改变已采集分页。原文与差异最多 200 行 / 12000 字符，差异最多 50 个可读文件，合并提交展开各父版本差异并保留父提交标识；Git 单命令 5 秒、stdout 4 MB，stderr 不混入 NUL 数据。只允许查询本地已知引用可达的完整提交 SHA。证据保存正文、SHA、采集时间及范围，历史引用不以新文件替换。

## 助手提问及回答恢复

原生问题必须属于当前远端 Session 和当前用户消息的助手子消息，限制每批/每请求最多 10 个问题、持久化内容最多 24000 字符。页面支持单选、多选及服务端允许的自定义回答；提交前不自动选定答案，刷新恢复本地草稿及未确认请求身份。已回答问题保留问答内容；问题卡显示真实等待状态。

问题是独立的交互投递记录，不修改会话/回合执行状态。回复先以版本 CAS、持久化幂等键登记 PREPARED，再由原回合 worker 进入 SENDING 并调用原 question reply 接口；成功记录 ANSWERED。相同键与内容重入返回原回执，变更内容拒绝；其他会话、旧轮次或停止后不得提交新回复。SENDING 遇到重启或外部结果未知进入 UNKNOWN，不自动重复投递；保留问题/答案，页面提供停止本轮后继续的恢复方式。等待问题时不把模型 idle 当作回答完成，停止确认后关闭未答问题。

## 接口

| 路径 | 能力 |
| --- | --- |
| `/api/knowledge/conversations` | 创建；项目/关键词/时间/状态/归档筛选和稳定游标查询 |
| `/{id}/archive`、`/{id}/questions/{question}/reply` | 版本化归档/恢复；幂等回答原问题 |
| `/{id}`、`/{id}/messages`、`/{id}/stop`、`/{id}/events` | 摘要、分页消息与幂等发送、确认停止、状态通知 |
| `/{id}/requests/{key}` | 按持久化请求身份核对是否已接收；刷新后清理已确认请求或恢复原草稿，不自动重发 |
| `/{id}/citations/{citationId}` | 所属会话内的引用元数据及正文 |
| `/api/projects/{id}/knowledge-sources` | 分页来源 |
| `/directories`、`/uploads`、`/{source}/refresh`、`DELETE /{source}` | 登记、上传、刷新及移除绑定 |
| `/{source}/directory`、`/content`、`/search`、`/database`、`/git` | 授权资料浏览、原文范围、检索、数据库结构及 Git 查询 |

写操作要求本地 UI 标识；绑定修改校验版本，发送校验持久化幂等键。真实 Provider、内网数据库与离线夹具的验收分别记录。

消息先返回最近一页，页内按时间正序显示；游标继续读取更早消息。会话摘要独立返回模型累计用量高水位，不因历史分页而少算。页面切换后的迟到读取、发送或停止回包不能覆盖当前会话。
